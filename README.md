# LicitaSeguro

## Integrantes

- Alvaro Vásquez
- Bruno Neira

## Descripción

Aplicación web desarrollada con HTML, CSS, Bootstrap y JavaScript que permite consultar licitaciones públicas mediante la API de Mercado Público.

## Funcionalidades

- Consulta de licitaciones
- Filtro por fecha
- Filtro por estado
- Validación de formularios
- Loader de carga
- Paginación
- Visualización de detalles
- Validación de RUT chileno
- Diseño responsivo

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6
- API Mercado Público

## Cómo ejecutar

1. Descargar proyecto
2. Abrir con VS Code
3. Ejecutar con Live Server
4. Utilizar los formularios disponibles
